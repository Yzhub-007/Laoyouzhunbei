# 测试案例与第4天演示脚本

> 版本说明：本文保留第1—4天的阶段记录。2026-10-02已增加两路公开最新气象接入；最新能力、数据边界与验收见[实时接入说明](08_实时数据接入说明.md)。CMA账户接口、官方预警、真实AI与现场试点仍未完成。

## 1. 案例性质

默认历史输入有可核验来源，但校园、点位与条目均为团队模拟。以下是开发验收用例，不能作为后续AI与模板对比的未见测试集；第7天需另外保留独立案例。真实用户效果尚未验证。

| 编号 | 输入变化 | 预期行为 | 检验点 |
|---|---|---|---|
| DEV-01 | 默认历史暴雨 | P01、P02、P03、P04、P06共5项，未选P05 | 暴雨不触发纯大风条目 |
| DEV-02 | 在完整模拟包中将灾种设为wind | P05和P06两项 | 灾种隔离；若编辑历史摘要需同步其来源和性质 |
| DEV-03 | 模拟复合rain＋wind | 共6项，P06不重复 | 去重 |
| DEV-04 | 气象城市改为厦门，场地仍福州 | 无匹配，说明不代表安全 | 地区限制 |
| DEV-05 | 回放时间提前至2023-09-05 20:00 | 拒绝生成 | 不使用未来资料 |
| DEV-06 | 清空来源链接 | 拒绝生成 | 来源可追溯 |
| DEV-07 | 重复点位编号 | 拒绝生成 | 资料质量 |
| DEV-08 | AI未配置 | AI按钮不可用；API明确报配置不足 | 不伪造AI能力 |
| DEV-09 | 模拟模型返回P99或不适用条目 | 拒绝整次结果 | 引用校验 |
| DEV-10 | 模拟模型额外输出行动命令 | 拒绝结果 | 不让生成内容越过条目限制 |
| DEV-11 | 输入含HTML标签 | 作为纯文本展示，不执行 | 页面注入检查 |
| DEV-12 | 修改输入后查看旧结果 | 旧结果被清空，需重新核对 | 输入与结果一致性 |

DEV-02和DEV-03只应使用完整标记为simulation的派生情景，不得把编辑后的灾种当作原始官方历史事件事实。自动化单元测试修改灾种是软件隔离测试，不是历史事件陈述。

## 2. 三分钟演示脚本

**0:00—0:25：问题和边界**

“我们做的是气象资料到场地任务的匹配。今天展示历史演练：气象来源可回查，校园与条目为示范，尚未完成真实试点。”

**0:25—0:55：查看输入**

展示2023年9月5日22时24分的资料时间、来源链接、人工摘要、适用区域和灾种。说明原文只涉及部分区域，不能仅靠城市名称推定具体场地。

**0:55—1:25：核对场地**

查看6个点位和5条草稿。指出地下入口、低洼通道和信息服务台等不同类型，以及纯大风条目。

**1:25—2:10：生成与检查**

确认演练范围后运行规则。展示5项任务，每项有点位、条目、来源、责任角色和待核验状态。明确此演示未调用AI，没有预测积水或宣布通行。

**2:10—2:40：导出复现**

导出Markdown与JSON。说明完整输入快照用于追溯与后续评估，不是用户效果证明。

**2:40—3:00：待完成事项**

“下一步补入真实点位与审核后的工作清单，完成外部模型调用和管理人员测试。AI是否更有效，将通过独立对照验证。”
