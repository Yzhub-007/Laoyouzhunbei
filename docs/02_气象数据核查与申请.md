核查日期：2026年10月1日。公开页面目录与实际登录下载能力分别记录。

## 1. 已确认的入口

用户提供的 [中国气象数据网首页](http://data.cma.cn/site/index.html) 通过直接HTTP访问返回正常页面，标题为“国家气象信息中心-中国气象数据网”。搜索工具读取及HTTPS访问出现不稳定，本次核查使用实际成功读取的公开HTTP页面。没有登录用户账户、创建账户、获取验证码或调用未公开接口。

主页当前提供的资料链接含 `/cmaOld/` 路径。优先使用从实际主页取得的链接，而不是假设旧收藏地址仍完整可用。

## 3. 最小数据申请规格

先围绕一个历史案例申请，不申请全国全量数据。

| 项目 | 建议请求 |
|---|---|
| 候选事件 | 2023年9月5日福州台风相关强降雨 |
| 请求时间 | 2023年9月4日至7日，实际可访问范围待确认 |
| 地域 | 福建省福州市，按实际试点和站点清单选择 |
| 站点 | 下载站点元数据后选择位置合适的站点；本次未核定站号 |
| 要素 | 站号、经纬度、观测时间、降水、统计时长、质量码；可选风速风向 |
| 附带资料 | 字段说明、时区、单位和缩放、缺测与特殊编码、使用许可 |
| 目的 | 历史背景与演练，不作实时预警、不作精细点位水深推断 |

建议步骤：

1. 用户自行进入官方网站账户，核对实名状态及访问权限，不将密码或验证码交给团队聊天工具。
2. 从资料详情进入官方检索；当前登录后的实际操作界面未验证，按钮名称以页面为准。
3. 确认资料是否覆盖目标时段，再选择福建/福州相关站点与必要字段。
4. 优先下载一个小样本及配套说明，核对格式后再扩大日期范围。
5. 保留原始文件；记录数据集名称、下载时间、使用范围和版本。
6. 上传给项目的是允许使用的文件及说明，不能直接提交账户凭据。
7. 若目标历史范围不可用，向主办方申请同一事件的授权或模拟资料；模拟必须单列。

只有网页检索或文件下载权限时，采用手工导入。没有实际取得API说明和权限前，不写“实时接口已接通”。

## 4. 下载后的清洗约定

标准字段建议：

```json
{
  "station_id": "从实际文件读取",
  "observed_at": "含时区的ISO时间",
  "available_at": "实际获得时间或未知",
  "rainfall_mm": null,
  "accumulation_minutes": null,
  "quality_code": "从产品说明解析",
  "source_dataset": "实际数据集名称",
  "source_file": "原始文件名称"
}
```

- 不假定时间是北京时间或UTC，先核对说明。
- 不假定降水单位和小数缩放系数，先核对字段元数据。
- 缺测、微量、特殊编码按说明处理，不能统一当0。
- 只在统计窗口兼容且无重复时累加降水。
- 观测时间、资料可获得时间和本次下载时间分别记录；不知道可获得时间时不做历史预警提前量结论。
- 不将日值或区域观测直接当校园点位的瞬时水情。
