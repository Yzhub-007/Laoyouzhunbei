测试覆盖未登录访问、三种角色、伪造 Origin、CSRF、仅持 Cookie 不得取得会话证明、密码长度和限速、过期和撤销、只读隐私字段过滤、公网模型阻断、DNS/IP 固定、TLS校验、不跟随重定向、ROI和遮挡、元数据清理、自由描述不入库、原图不自动落盘、跨进程存储锁、密文篡改、迁移失败回滚、保留期、配置改变后旧观测失效。

浏览器测试使用独立测试账号和数据库，未替正式用户设置密码。测试后的临时账号库和测试服务已清理；正式页面保持首次管理员设置状态。截图在同目录的 `auth`、`monitor`、`zju` 子目录，包含桌面及390px布局。

## 数据迁移

主库迁移前后均保留2条历史运行和1条实时参考快照，建档与试验表原本为空。迁移前后数量、密文头及接口访问状态见 `migration-before.json`、`production-verification.json`。迁移前已停止旧服务，避免同时读写旧 SQLite。

4个既有 QA 数据库也已保留数据并加密，详见 `historical-migration.json`。加密恢复副本仍保留，未自动删除。外部导出、旧压缩包和截图不属于数据库迁移，保留原文件。

本机账户归属在部署时单独验证：开发沙箱账户与日常 Windows 账户不同，不能直接把沙箱密文交给日常启动脚本。已使用一次性加密转移工具将11个受保护文件（含5个库、5份备份和账户库）在内存中重封装至日常账户；转移内容仅以加密包落盘，不写明文数据库。正式账户下5个库及其备份均可解密，原记录数量不变，服务也由日常账户启动。验证记录为 `owner-verification.json`，迁移收据为 `owner-transfer-receipt.json`。一次性转移包及其临时私钥已清理，恢复副本保留。

最终正式页面检查确认：首次设置页可见、业务工作台隐藏、匿名身份接口不返回会话证明，没有预设正式账号。截图为 `evidence/security/production-setup.png`。初始化码文件仅允许日常 Windows 账户与 SYSTEM 访问。
