# v0.5 自动监测版本验证

验证日期：2026-10-03，北京时间。

## 已验证

- 114 项 Python 自动测试通过，覆盖原有演练规则、实时气象、审核与计时试验，以及新增监测配置、摄像头抓拍、时间校验、连续判断、重复帧、错误隔离、人工校正和 HTTP 接口。
- HTTP 抓拍 → 图片 Base64 输入 → 视觉响应解析 → 点位疑似积水 → 自动匹配预案的本机端到端测试通过。图片与视觉响应为合成测试夹具；相同图片第二次轮询不会再次调用视觉服务。
- 新监测首页 18 项浏览器检查通过：配置保存与版本冲突、草稿保留、人工校正时效、断线清除旧状态、待核验标记、390px布局和无脚本错误。
- 原有工作流 27 项浏览器回归检查通过：生成规则清单、任务审核、公众提示草稿、反馈、历史恢复、建档和计时试验。
- 当前服务的 Open-Meteo 与机场 METAR 均取得新近数据；生产数据库未添加虚构设备，6个待建档点位均显示未知。
