> 版本说明：本文保留第1—4天的阶段记录。2026-10-02已增加两路公开最新气象接入；最新能力、数据边界与验收见[实时接入说明](08_实时数据接入说明.md)。CMA账户接口、官方预警、真实AI与现场试点仍未完成。

核验日期：2026年10月1日。以下为软件验证，不是气象模型效果或真实用户试点成绩。

## 1. 后端测试

执行方式：`python -m unittest discover -s tests -v`。

结果：17项通过。覆盖暴雨、大风、复合灾种、回放时间、时区、地区不匹配、范围确认、来源缺失、危险链接、重复编号、实时模式拒绝、API未配置、合法模型选择、错误引用、额外生成字段、格式错误以及规则模式中的指令文本隔离。

AI有关测试使用模拟HTTP响应，不调用真实模型，不证明模型准确率或抗提示注入能力，只检验程序对响应的约束。

## 2. 浏览器与HTTP检查

浏览器：本机Edge无头模式。桌面视口1440×1100，窄屏视口390×844。20项检查通过，详见 [browser-checks.json](../evidence/browser-checks.json)。

关键结果：

- 默认资料载入成功，明确展示历史演练。
- AI未配置时按钮禁用。
- 6个示范点位载入；默认暴雨匹配5项任务，未包含纯大风点位。
- 未确认范围时阻止生成。
- 修改输入后旧结果清空。
- 地区不匹配显示无任务但不宣称安全。
- 发布时间晚于回放时刻时拒绝。
- 导入的HTML标签以文本显示，不执行。
- Markdown与JSON导出成功，后者包含输入快照。
- 390px下三个页面未检测到水平溢出。
- 页面没有浏览器脚本错误。
- 浏览器未收到密钥字段；缺少请求令牌返回403；访问.env返回404。

窄屏检查是桌面浏览器模拟，不等于手机真机测试。实际输入键盘、触摸和系统浏览器行为待用户真机确认。
