# v0.8 优化与验证记录

日期：2026-10-04（北京时间）。本版优先修复日常管理中的资料丢失、历史查找与运行可靠性问题，保留 v0.7 的监测、预案、权限和验收功能。

## 完善内容

| 原有问题 | v0.8 行为 |
| --- | --- |
| 读取数据库也改变 SQLite 文件头，触发全库重新加密落盘 | 仅新建空库做初始化；纯读取保持原密文与文件修改时间，实际写入仍原子加密保存 |
| 表单可能被恢复记录、载入资料或退出操作覆盖 | 当前页面内存中跟踪草稿；覆盖和离开前提醒，切换页签保留。保存期间锁输入，失败保留草稿 |
| 预案保存成功但后续列表刷新失败被误认为保存失败 | 提示具体版本已保存，可重试刷新列表，无须重复提交 |
| 版本记录固定显示最近 200 条 | 每页 30 条，支持标题、点位、草案/复核状态筛选，并加载更早版本 |
| 预案时效提示可能停留在旧检查结果 | 重新进入或刷新时核验当前已保存文档，不覆盖编辑与复核意见；失败明确提示 |
| 停止监测后迟到请求仍可能提交结果 | 停止信号与本地提交协调，迟到天气、设备、摄像头及天气缓存不再提交 |
| 轮询中收到刷新请求可能被清除 | 保留并合并刷新信号，当前轮询完成后再采集 |
| 更换端口可能重复使用同一运行目录 | Windows 进程锁阻止同一目录同时启动两个服务，退出自动释放；拒绝链接和目录联接 |
| 服务主循环结束时请求可能还在写入 | 等已接入请求结束并关闭服务后，才释放运行目录锁；接入 socket 设置 15 秒空闲读超时 |

草稿仅存当前页面内存，不写入 localStorage 或会话存储。浏览器离开提醒无法保护强制结束进程、浏览器崩溃或安全会话失效；应及时保存。会话失效仍立即清除页面资料，不为了保留草稿绕过登录。

导出和内部复核针对页面展示的已保存版本，表单中未保存的编辑不会自动进入导出或复核文档。全部输出仍为草案，不代表正式批准或发布。

## 验证

Windows、Python 3.12.14、Pillow 12.3.0、Edge headless。

- 后端最终运行 **250 项测试，249 项通过，1 项跳过，无失败**。跳过项是当前 Windows 测试账户没有创建文件符号链接权限；真实目录联接拒绝、链接祖先检查、跨进程争用与异常/退出释放均通过。
- 浏览器 **163 项检查通过**：账户与权限模拟 29、真实登录 10、监测界面 18、工作流 28、预案流程 42、新增草稿/筛选/时效 36。
- 新增历史查询测试验证 245 个版本可以全部回查；两次分页之间新增版本不会造成重复或遗漏旧记录。标题 `%`、`_` 按字面匹配，查询参数重复/溢出/越权被拒绝。
- 真实 DPAPI 临时文件测试验证连续只读不改密文和修改时间，真正修改持久化，异常事务保留原文件。
- 阻塞假来源测试验证迟到结果不会提交；真实本地阻塞请求验证关闭期间实例锁持续持有。
- 手机页面以 390 像素浏览器视口检查横向溢出，并检查桌面/手机截图；不属于真实手机现场验收。

全部写入测试使用独立临时目录和合成资料。部分上游与错误场景为模拟，真实设备、真实模型与现场识别效果不在此次验证范围。

## 使用和交付

现有服务更新为 `0.8-reliability`，继续使用原 Windows 账户及其加密运行资料。主库升级前加密备份留在本机 runtime。升级会结束旧登录会话，使用原账号重新登录即可；不会重新初始化管理员。

压缩包由 build_release.py 生成，仅包含源码、页面、合成模板、测试、操作文档与安装入口；runtime、真实账号、密钥、监控资料、截图、虚拟环境和模型权重均排除。包内 RELEASE_MANIFEST.json 提供逐文件 SHA-256，整包另有 `.zip.sha256` 校验文件。

同一 runtime 的第二个进程会被拒绝；不要删除正在使用的锁文件。服务启动时须由原日常 Windows 账户运行。首次从旧版升级时，先停止原实例；旧版本没有新实例锁，不能假定新版本能阻止旧代码同时运行。跨机器/账户的 DPAPI 数据恢复仍需单独验证，不能直接复制运行目录当作完成迁移。

项目仍是管理辅助原型。实际摄像头、视觉模型和正式预警需单独接入；现场样本验收、正式管理授权与专业安全评估仍由使用单位完成。
