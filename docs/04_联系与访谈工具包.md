## 3. 15分钟访谈提纲

| 时间 | 问题 | 记录重点 |
|---|---|---|
| 0—2分钟 | 您负责哪些区域和工作？通常从哪里收到气象或防汛信息？ | 用户角色、边界、资料来源 |
| 2—5分钟 | 回想最近一次强降雨，从收到消息到采取行动经历了哪些步骤？ | 真实过程，不先推销方案 |
| 5—8分钟 | 哪一步最费时、容易遗漏或难以确认？能举一个具体例子吗？ | 可验证的痛点和已有解决方法 |
| 8—10分钟 | 判断哪些地点要关注时，通常查看哪些台账或预案？ | 资料名称、获取权限、维护人 |
| 10—12分钟 | 谁能确认现场状态、谁能决定入口关闭或发布通知？ | 权限边界与责任角色 |
| 12—14分钟 | 如果工具提供任务草稿，哪些信息必须保留？出现什么错误您就不能用？ | 正确性标准与否决条件 |
| 14—15分钟 | 是否愿意核对一组脱敏点位/条目，或安排一次历史演练？ | 具体下一步、人员、时间 |

不要把“您觉得AI是否有用”当作核心问题。优先询问过去行为和具体流程。
