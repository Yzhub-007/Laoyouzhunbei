# 安全配置与使用边界（v0.6）

适用于当前 Windows 本机版本。目标是限制画面外发、减少敏感内容保存、防止未登录与越权访问，并保护磁盘资料；不能保证不存在漏洞，也不能对已被控制的操作系统提供隔离。

## 账户与权限

首次管理员由持有本机 `runtime/setup-code.txt` 的用户创建。码有效20分钟、单次使用；过期可执行 `python security_cli.py setup-code`。用户名3—64位英文字母、数字、点、短横线或下划线，密码15—128字符。密码加随机盐，通过 PBKDF2-SHA256（600000轮）处理，不保存明文。

| 操作 | 管理员 | 操作员 | 只读用户 |
|---|---|---|---|
| 查看监测、历史与演练结果 | 是 | 是 | 是，经过隐私字段过滤 |
| 生成演练、采集、写入观测、现场核验 | 是 | 是 | 否 |
| 配置监测来源、保存建档 | 是 | 否 | 否 |
| 管理账户及角色 | 是 | 否 | 否 |
| 修改自己的密码 | 是 | 是 | 是 |

服务端逐个接口检查权限；隐藏按钮只是辅助。审核与人工校正身份来自登录会话。尚无设备专用权限：接入代理使用操作员账户时也拥有该角色其他写权限，不能将会话交给不可信设备。

会话随机生成，服务端内存仅存其摘要；Cookie 为 HttpOnly、SameSite=Strict，不写入 localStorage。所有受保护请求还必须携带登录时取得的独立证明（X-App-Token）；浏览器将此证明仅保存在按完整 origin 隔离的 sessionStorage（laoyou.csrf），刷新可继续，退出会清除。其他本机端口即使收到 Cookie，也不能凭 Cookie 单独换取身份或令牌。同源脚本若被攻破仍可能读取此证明，因此保留严格 CSP 和安全文本渲染。闲置30分钟或总时长8小时失效；重启、退出、改密、停用或账户调整使相应会话失效。单账户5次或全局25次失败触发5分钟限制，失败状态持久化。写请求检查精确 Origin、JSON 类型及会话 CSRF 标识，拒绝跨站访问。登录及账户变更留加密审计，最多1000条、30天；不是覆盖所有业务操作的独立审计平台。

## 图像与网络

默认只允许 loopback 模型和抓拍接口。本机外服务必须同时满足 HTTPS、精确 origin 授权、所有 DNS 解析结果属于允许的私有网络。公网、链路本地及元数据地址被拒绝。连接固定到已检查 IP，TLS 验证原主机名及证书，不读取环境代理，不跟随重定向。

分别录入 `VISION_TRUSTED_ORIGINS`、`CAMERA_TRUSTED_ORIGINS`、`MONITOR_TRUSTED_ORIGINS`、`LLM_TRUSTED_ORIGINS`，只授权实际用途。例如 `https://camera.campus.example:443`，必须显式包含端口，不带路径或末尾斜杠；多个 origin 用逗号分隔或 JSON 数组。域名必须在实际网络解析为授权私有地址并有有效证书，不提供跳过证书校验的开关。白名单不能使公网地址获准。

使用 `python security_cli.py set-secret VISION_ENDPOINT` 等命令隐藏录入值。VISION 使用独立 ENDPOINT、API_KEY、MODEL；LLM 用相同字段结构。秘密不放入命令参数、聊天或源码。保存于 `runtime/secrets.dpapi`，修改后重启。环境变量可覆盖同名值，但环境变量本身不受本项目加密保护。

摄像头按完整图片归一化坐标设置 `roi: [x,y,w,h]` 和 `privacy_masks: [[x,y,w,h], ...]`。先校正方向、遮挡，再裁剪及重新编码，移除 EXIF 等元数据。发到本机外校内模型时必须设置非全图 ROI。ROI 仍可能包含人物，需要管理员按点位视角设置并用现场素材确认；没有自动人脸/车牌检测和动态跟踪打码。裁剪、遮挡或模型配置变化后旧证据失效。

应用不自动保存下载的抓拍原图，发送图像只在内存中处理；本地文件接入时网关预先写入的图片仍需网关设置权限与清理。模型自由描述不进入监测观测，只保存结构判断及固定摘要。模型服务自身可能记录输入，需在服务端关闭图像日志并验证；本项目无法控制其备份、训练或日志策略。

RTSP/RTSPS 直连当前停用，使用受控 HTTPS 抓拍网关。HTTP 抓拍需要 Pillow，缺少库则停止识别，不降级发送原图。

气象模块仍访问既定公共天气接口，仅传公开经纬度/站号。完全离线环境需另配气象内网镜像或停用公共上游，不应把本版理解为完全离线系统。

## 存储、迁移与保留

SQLite 在内存中打开，提交后序列化并通过 Windows DPAPI 当前用户加密，再原子替换磁盘文件；不建立明文 SQLite 临时副本。JSON 配置同样加密。ACL 仅允许当前 Windows 用户及 SYSTEM。非 Windows 环境不静默退回明文。数据库上限64 MiB，达到限制应规划归档。

`runs.sqlite3` 保留文件名，但已不是可直接打开的普通 SQLite。旧文件首次迁移生成 `*.migration.dpapi` 加密恢复副本；未完成 WAL/事务日志会阻止迁移，须先关闭旧进程并正确完成事务。加密失败保留原状态，不以明文继续写入。配置也保留一次性加密迁移副本。

正式服务必须从日常 Windows 账户启动，不要将开发沙箱账户生成的密文直接用于日常启动。DPAPI 绑定 Windows 账户及密钥环境，简单复制到其他机器/账户不保证可解密。备份须包括相应账户密钥恢复方案并实际演练；不要删除旧账户后才尝试恢复。迁移不等于擦除曾经存在的明文痕迹，磁盘加密、系统备份、分页文件属于操作系统管理。同一 Windows 账户的恶意软件、管理员或 SYSTEM 仍可能访问解密内容。

| 数据 | 默认保留 | 可设置范围 |
|---|---|---|
| 监测观测 | 7天 | SECURITY_OBSERVATION_DAYS：1—30天 |
| 监测事件 | 30天 | SECURITY_EVENT_DAYS：1—90天 |
| 人工校正 | 30天 | SECURITY_CORRECTION_DAYS：1—90天 |

用 `security_cli.py set-secret` 录入天数，重启生效；按规则清理并维持原有数量上限。历史运行清单、试验记录和建档不自动删除；加密恢复副本不自动过期，确认迁移及备份可恢复后由管理员清理。本轮已将发现的4个历史 QA 库一并加密，保留记录及加密恢复副本。外部导出、旧压缩包和人工截图不会自动重新加密或删除；主库保护不能理解为所有历史文件均已处理。公开天气缓存仅含公共气象内容，不属于秘密存储。

## 部署范围与验收

服务器只绑定 `127.0.0.1` 并验证 Host。浏览器到服务端使用本机 HTTP，因此 Cookie 未设 Secure；不是可直接开放端口的内网或公网部署方案。同机进程与相同浏览器站点范围内其他服务属于操作系统信任边界。跨机多人访问须另行实现完整 HTTPS 部署、代理信任规则、网络访问控制及专项验收。

真实摄像头、网关证书、昼夜和遮挡下识别、ROI、模型日志策略、设备固件、账户权限和数据恢复仍需现场验证。自动识别仅作待核验提示，不能自动作为道路开放、撤离结束或解除警报的依据。
