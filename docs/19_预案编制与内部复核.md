# 点位预案编制与内部复核

v0.7 将已保存建档、有效监测快照和适用预案条目整理成可审阅、可留存的文档。它使用确定性规则，不依赖文字模型，也不会向模型发送联系人或场地资料。输出始终是草案，内部复核后仍不能作为正式批准的应急预案。

## 编制前准备

管理员先在“试点建档”保存真实场地、管理范围、授权记录、点位及预案条目。仅在其他页面临时编辑而未保存的资料不会用于编制。当前试点建档限定杭州市紫金港校区；默认楼宇和六个点位是待确认槽位。

真实预案至少需要：管理授权、经核验的点位、适用且未过期的正式条款、责任岗位与联络方式、物资设施、启动/停止条件、报告升级关系、疏散安排与交接复查要求。系统不会推断这些管理事实，留空就会显示待补充。

## 操作步骤

1. 用管理员或操作员登录，打开“预案编制”。
2. 选择一个或多个已保存点位，填写草案名称和管理方确认的补充资料。
3. 点击“生成预览”，检查待补项、天气与点位观测、条目来源及任务适用性。没有现场来源的点位保持未知。
4. 点击“保存为新版本”。每次保存重新取得监测快照并新增版本，旧版本不被覆盖。
5. 管理员打开“管理员内部复核”，说明核对范围及遗留问题；保存后形成新的“已内部审阅的草案”版本。此前版本仍保留。
6. 点击“导出可打印文档”或“导出完整数据”。HTML 可独立在浏览器打开并打印/另存为 PDF；JSON 保留结构化依据。

v0.8 的版本记录默认每页 30 条，可按标题、点位和复核状态筛选，点击“加载更早版本”继续回查。分页不会删除旧版本。选择历史版本会将它的补充资料载入表单，预览中仍显示当时的观测；再次生成预览或保存时使用当前已保存资料与最新有效监测。

多窗口或多人会话同时保存时，服务端检查版本号，过旧请求返回冲突。页面保留表单输入；点击“刷新建档与版本”，核对变化后重新保存。刷新建档不会清空已经填写的补充资料。

## 依据与时效

- 点位及条目必须属于建档地区与校区，并满足条目的点位类型/编号范围。过期条目不生成建议任务。
- 草稿条目可以作为待核验备用清单，但明确标记未核验，不会变成正式执行授权。
- 使用编制时仍有效的观测。模拟或历史演练天气不会冒充当前天气；图像识别不能提供实际水深或安全通行结论。
- 有参考信号的任务标记“有监测线索，待现场核验”；没有参考信号的任务仅为“备查条目”，不会自行启动。
- 有效的人工校正保留有效期含义，到期后不再沿用其状态。
- 重新打开或导出历史版本时，会对照当前建档与监测，提示资料变化、观测变化或条目过期。历史观测不会被悄悄替换成新观测。

## 权限与保存

预览、列表、详情、保存和导出仅供管理员、操作员；只读账户不能获取文档。内部复核仅供管理员。所有接口检查账户会话及同源校验，包括下载。

草案存在主数据库的受保护版本表中，使用现有 Windows 当前账户 DPAPI 加密。文档只提取必要来源字段，不附相机地址、认证字段、图像或原始模型回复。导出的 HTML/JSON 会包含管理人员主动填入的内部联络与资源资料，是未加密的可读文件，需要按照内部资料保管。

可打印 HTML 的动态内容全部作为文字转义，不执行填写内容中的脚本，也不引用外部字体、脚本或图片。保存/复核与导出不发送通知、不对外发布、不下达处置命令。

## 接口概要

| 接口 | 用途 |
| --- | --- |
| `GET /api/response-plans` | 当前版本号、筛选后的总数和游标分页摘要 |
| `POST /api/response-plans/preview` | 选择点位并生成预览 |
| `POST /api/response-plans/save` | 以 `expected_revision` 保存新版本 |
| `GET /api/response-plans/{id}` | 查看独立历史版本及更新提醒 |
| `POST /api/response-plans/review` | 管理员填写 `review_note`，创建复核版本 |
| `GET /api/response-plans/{id}/export?format=html` | 导出可打印文档，`format=json` 导出数据 |

预览/保存接受 `point_ids` 和 `details`，补充字段为 `title`、`contact_roster`、`resources`、`activation`、`escalation`、`evacuation`、`recheck`。标题最多 160 字，其他字段各 4000 字。点位数为 1—30，不能重复，也不能引用未保存点位。


## v0.8 编辑与时效保护

试点建档、监测配置、预案及内部复核意见的草稿仅在当前页面内存中保留。可能覆盖草稿的操作会先提醒；正常切换页签保留草稿，保存失败不清除输入。关闭/刷新网页由浏览器显示离开提醒，强制结束进程或会话失效无法保证保留，完成填写后应及时保存。

重新进入预案页或点击刷新会重新检查已保存预案的时效，保留正在编辑的补充资料和复核意见。检查失败会说明未能完成核验；执行前仍需重新查看现场证据。尚未保存的预览需要重新生成才能采用最新证据。

版本列表查询支持 `limit`（1—100，默认30）、`before`（版本游标）、`q`（标题文字，最多100字）、`point_id` 与 `status`（draft/reviewed_draft）。响应中 `revision` 是全局最新版本，`total` 是筛选后的总数，`next_before` 和 `has_more` 用于继续加载。并发新增版本不会使下一页重复显示已经加载的旧版本。
